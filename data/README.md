# Data

`online_retail_2009.csv.gz` and `online_retail_2010.csv.gz` — the two tables of the
*Online Retail II* dataset, as the shop's own system recorded them.

What each file holds, and what one of its rows stands for, are among the things the
notebook asks you to establish.

Source: UCI Machine Learning Repository, *Online Retail II* (Daqing Chen),
<https://archive.ics.uci.edu/dataset/502/online+retail+ii>, CC BY 4.0.

Converted from the original spreadsheet to CSV and compressed with gzip. No values were
altered.
